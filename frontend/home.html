Core Capabilities

Security insights, made simpler.

SentinelX brings essential threat-analysis concepts into one interface, helping users examine request events and understand why an event may be suspicious.

⌕

Threat Detection

Apply predefined rules to identify suspicious patterns, including repeated failed logins and unusually high request rates.

◉

Risk Scoring

Assign a risk score to analyzed events and classify them into High, Medium, or Low severity categories.

▥

Security Dashboard

View event summaries, severity counts, and recorded threat events in a single dashboard interface.

⚑

Threat Alerts

Present high-severity findings in a dedicated alert panel so important results are easier to review.

▣

Event History

Keep a record of analyzed events for reviewing results and demonstrating the detection workflow.

⌘

Simple Interface

Use a clean, responsive interface designed to make cybersecurity concepts more accessible to students and beginners.

The Workflow

How SentinelX works

Explore the basic workflow used by this project to examine request events and display a threat assessment.

01

Submit an Event

Enter event details such as an IP address, request path, failed login count, and requests per minute through the dashboard form.

02

Analyze the Request

The C++ detection logic evaluates the submitted values against predefined rules and calculates a risk score.

03

Review the Result

View the severity classification and recorded event details in the dashboard to understand the result of the analysis.

About the Project

Understand the signals behind potential threats.

SentinelX is a learning-oriented cybersecurity project that demonstrates how request information can be evaluated using rule-based detection. It connects a web interface with a C++ backend and supports the review of analyzed events.

  • ✓ Rule-based event analysis using C++
  • ✓ Risk scoring and severity classification
  • ✓ Web interface built with HTML, CSS, and JavaScript
  • ✓ Backend event handling and storage integration
